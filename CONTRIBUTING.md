# Beitrag zum Multiboot-Guide

Vielen Dank für dein Interesse, zu diesem Projekt beizutragen! 🎉

## Wie kann ich beitragen?

### Fehler melden

Wenn du einen Fehler im Guide findest:

1. Überprüfe zunächst, ob der Fehler bereits als [Issue](https://github.com/artifex-vision/guide-multiboot-ashai-mac-m/issues) gemeldet wurde
2. Falls nicht, erstelle ein neues Issue mit:
   - Einer klaren Beschreibung des Problems
   - Schritte zur Reproduktion (falls zutreffend)
   - Erwartetes vs. tatsächliches Verhalten
   - Deine Systemkonfiguration (Mac-Modell, macOS-Version, etc.)

### Verbesserungen vorschlagen

Hast du Ideen zur Verbesserung des Guides?

1. Erstelle ein Issue mit dem Label "enhancement"
2. Beschreibe deine Idee detailliert
3. Erkläre, warum diese Verbesserung nützlich wäre

### Pull Requests

Pull Requests sind willkommen! Folge bitte diesen Schritten:

1. **Fork** das Repository
2. **Erstelle einen Branch** für deine Änderung:
   ```bash
   git checkout -b feature/meine-verbesserung
   ```
3. **Mache deine Änderungen**:
   - Halte dich an den bestehenden Stil
   - Schreibe klare, präzise Anweisungen
   - Teste alle Befehle, die du hinzufügst
4. **Commit** deine Änderungen:
   ```bash
   git commit -m "Füge XYZ hinzu: kurze Beschreibung"
   ```
5. **Push** zu deinem Fork:
   ```bash
   git push origin feature/meine-verbesserung
   ```
6. **Erstelle einen Pull Request** mit:
   - Klarer Beschreibung der Änderungen
   - Referenz zu relevanten Issues
   - Screenshots (falls UI/Layout betroffen)

## Stilrichtlinien

### Markdown-Formatierung

- Verwende `#` für Hauptüberschriften, `##` für Unterüberschriften, etc.
- Nutze Code-Blöcke mit Syntax-Highlighting: \`\`\`bash
- Füge Leerzeilen zwischen Absätzen ein
- Verwende Listen für Schrittfolgen
- Nutze Tabellen für vergleichende Informationen

### Sprache und Ton

- **Sprache**: Deutsch (du-Form für Anleitung)
- **Ton**: Freundlich, hilfreich, aber präzise
- **Erklärungen**: Verständlich für technisch versierte Einsteiger
- **Warnungen**: Kennzeichne wichtige Hinweise mit ⚠️

### Code-Beispiele

- Teste alle Befehle bevor du sie hinzufügst
- Füge Kommentare hinzu, wo nötig
- Verwende realistische Beispiele
- Erkläre Platzhalter (z.B. `deinname`, `disk0s5`)

### Struktur

- Logische Reihenfolge der Schritte
- Klare Überschriften
- Inhaltsverzeichnis aktualisieren
- Links auf externe Ressourcen prüfen
