# Dokumentations-Verzeichnis

Dieses Verzeichnis enthält zusätzliche Dokumentation und Ressourcen für den Multiboot-Guide.

## Struktur

```
docs/
├── images/          # Screenshots und Diagramme
└── README.md        # Diese Datei
```

## Images

Das `images/` Verzeichnis ist für Screenshots und visuelle Hilfsmittel vorgesehen:

- Screenshots vom Installationsprozess
- Diagramme zur Partitionierung
- Boot-Menü Beispiele
- Fehlerbehandlung visuelle Guides

## Beiträge

Wenn du Screenshots oder Diagramme hinzufügen möchtest:

1. Speichere Bilder in `docs/images/`
2. Verwende aussagekräftige Dateinamen (z.B. `asahi-installer-step1.png`)
3. Optimiere Bildgrößen (max. 1920px Breite empfohlen)
4. Referenziere Bilder im README mit relativen Pfaden
5. Füge Alt-Text für Barrierefreiheit hinzu

### Beispiel

```markdown
![Asahi Installer Schritt 1](docs/images/asahi-installer-step1.png)
```
